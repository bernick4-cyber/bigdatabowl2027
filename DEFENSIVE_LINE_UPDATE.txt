Keep the current data folder and all other application files. This package
is an update, not a standalone replacement repository. No requirements change
is needed. After committing, let Streamlit redeploy and open Defensive Line Lab.

Includes coverage, player comparisons, combine relationships, and a draft-class
test. Select measurements and click Evaluate 2025 draft class to run the test.
Training uses 2023–2024. All models use the same complete player sample.

Default outcome: mean recorded get-off on identified dropbacks in rookie
regular-season, non-nullified plays. Rule: pass_result C, I, IN or S; R only
when the description explicitly says scramble. Missing/unknown codes and
other R plays are excluded. This is a proxy for pass-rush opportunities,
not a confirmed individual rush-assignment label. Blitzing is not used.
The all-recorded-play view remains available as a reference. Data coverage
includes the effect of the filter for every player, including ineligible ones.
Exports now identify the sample, added measurements and observation threshold.
Default minimum: 20 recorded get-off observations. Sacks are descriptive totals,
not opportunity-adjusted rates. Edge = DE; interior = DT or NT. OLB excluded.

Results are exploratory. Inspecting 2025 and changing inputs means it is no
longer an untouched final test. NGS score timing and training cohorts have not
been verified. Faster get-off alone does not establish better defensive play.

Validation command: python -m unittest test_defensive_line.py
